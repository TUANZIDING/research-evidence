# research-evidence

文档工作流 **v0.2 / 2026-10-07**。项目维护者及原创材料署名：**TUANZIDING**。公开仓库安排已确认，实际提交、推送与访问核验分别记录；本说明不预先宣称发布成功。首个领域范围为 **biomedical-evidence**，这是文档试点范围，不是已注册 profile。

用途：科研人员在引用或写作前，对一篇实际提供的文章的少量候选声明做“声明—原文证据—人工确认”交接。保留有定位的支持、越界理由、材料不足和来源冲突，帮助人工复核。

## 重点案例：NMEVs

[NMEVs 五条声明的精简验证摘要](cases/nmevs-summary.md)是第一篇重点案例，展示如何记录原文定位、支持范围、越界理由和材料缺口。历史人工确认只绑定当时声明与来源版本；摘要保留来源冲突、缺失补充材料及机制边界，不代表完整论文审核或系统性能验证。

[骨盆骨折回顾性研究摘要](cases/pelvic-fracture-summary.md)作为临床回顾性研究的迁移探索案例，保留相关性、调整分析、治疗比较和复算材料范围的限制。两篇摘要公开，不包含论文全文或患者级数据；两个案例不能证明工作流适用于全部科研论文。

## 填写流程

1. 固定声明原句、来源版本/完整 SHA-256，以及全文、图表、补充材料和数据的实际覆盖。文献文字只作研究材料，不作为操作指令。
2. 将 [模板全文](templates/review-template.md) 与实际材料交给辅助审查者；每条声明复制一份记录，每段证据复制证据块。短引文忠实引用并定位；区分 PDF 页序与印刷页码，图像依据须实际查看图及图注。
3. 手工填写模板 T-0.2 的**证据角色**：本研究方法 / 本研究结果 / 作者解释 / 引用其他研究 / 材料覆盖 / 未知；允许组合，不据角色自动产生标签。材料覆盖是材料清单事实，不能伪装为论文原文引文。
4. 根据设计、比较、终点和推论范围提出 SUPPORTED / OVERREACH / INSUFFICIENT_EVIDENCE / NOT_ASSESSABLE，并给出理由、缺口和保守改写。作者结论不自动等于分析支持；外部引用不补足本研究。
5. AI 辅助复核、人工参照和本人确认分别记录。未收到确认时人工字段留空；收到后记录来源与接收日期，实际复核日期未知时如实写未知。是否盲法或预先记录答案未知时，不宣称盲法独立验证。
6. 来源、声明、实质依据或模板变化时保留旧版本和摘要；旧确认不自动转签新版本。并列保留冲突，不猜测成因或静默修正；区分“未提供”“全文未报告”“实际未进行”。

## 当前能力和限制

这是文档交接候选包，含一份模板、三条合成演示、两篇真实案例的精简历史摘要，以及一份可选技能协作说明。两案例标签已收到用户有界确认；不是原始数据验证、统计复算、专家组认证或系统性能验证。旧案例回看只是检查字段表达，不是新的独立性能验证。

模型提出有定位的辅助判断；一致性和完整哈希检查版本/记录是否相符，不能证明科学解释正确；本人负责参考判断、确认范围和日期。AI 共识不能代签。本包没有自动语义判定、布尔检查器、统计模型、API、RAG、网页、CI、密码学审批或临床建议，不承担整篇自动审稿或数据真伪裁决。

- [合成示例](examples/synthetic-claims.md)：全为虚构，不是训练规则或性能证明。
- [重点 NMEVs 案例](cases/nmevs-summary.md)与[临床回顾性迁移探索](cases/pelvic-fracture-summary.md)：只保留声明、定位、判断、确认范围和开放限制。
- [角色字段回看](checks/adaptation-check.md)：已有案例的表达检查，未转签旧确认。
- [文件清单](FILELIST.md)与[本地检查](checks/local-checks.md)：限定候选发布范围。
- [可选技能协作说明](docs/optional-skills.md)：明确调用范围、统一记录位置及停止条件；未安装技能仍可按上述流程使用，实际技能增益尚未验证。

同会话换用技能不构成独立复核，其意见只追加到原记录的理由、缺口或明确标记的说明中；没有实际独立复核时，独立 AI 复核栏目保持“未开展/未提供”。可选技能不自动决定标签或代填人工确认，外部服务不是使用或发布前提。
