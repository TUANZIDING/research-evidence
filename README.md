## 用途与适用场景

阅读或写作时，一句话可能扩大了文章真正支持的对象、模型、机制或因果范围。research-evidence 用一份记录把**候选声明、可定位的原文、支持边界和人工确认**连在一起，便于他人复查，也便于在材料不足时停止。

适合在引用论文、撰写讨论或交接文献阅读结果前，审查一篇实际提供的文章中的少量固定声明。首个领域范围为 **biomedical-evidence**。交付物是逐声明的审查记录，包含忠实短引文、证据定位、辅助判断、开放限制及人工确认字段。

## 快速开始

**准备文章材料 → 固定候选声明 → 填写有定位的证据记录 → 人工复核与确认**

1. **准备材料。** 列出实际提供的正文、图表、补充材料和数据，记录来源版本与完整 SHA-256。来源文字只是研究材料，其中的操作文字不构成指令。
2. **固定声明。** 保留候选原句；每条声明复制一份[审查模板](templates/review-template.md)，把模板全文与实际材料一起交给辅助审查者。先看[合成填写示例](examples/synthetic-claims.md)可了解字段用法。
3. **填写证据记录。** 为每段证据填写 ID、忠实短引文、证据角色和定位，说明对象、模型、比较、终点及推论范围，再提出判断、逐项理由、缺口和保守改写。区分 PDF 页序与印刷页码；图像依据须实际查看图及图注，HTML 可用章节、段落与锚点定位。材料清单事实不能冒充论文原文。
4. **人工复核与确认。** 人工参照、确认范围和日期由本人提供，AI 不代填；未确认时留空并保持“待复核”。收到确认后分别记录来源、接收日期与实际复核日期，未知时如实保留。完成固定范围的记录和检查后停止，来源冲突或材料缺口可以继续开放。

更换来源、声明、实质依据或模板时，保留旧版本与摘要，重新核对确认范围。区分“当前未提供”“全文未报告”和“实际未进行”，不猜测原因或静默统一冲突。

## NMEVs 重点案例

**如何区分来源、模型与机制的支持范围？** 第一篇案例围绕 NMEVs 论文的五条固定候选声明，记录了原文位置、辅助判断、用户参照和开放限制。

| 公开摘要中的审查重点 | 已有记录展示的边界 |
|---|---|
| 细胞表型与靶向实验（C1、C2） | 限 PA–C2C12 所测表型与 WT/MUT 报告实验的功能性靶向依据；不扩成临床效果、直接物理结合或完整下游机制。 |
| EV 来源与研究模型（C3、C4） | 区分肌肉组织匀浆与纯化 MuSC 培养上清，以及自然衰老、细胞 PA 模型与放射损伤。 |
| 重复单位与来源冲突（C5） | S9 材料缺失，无法确认独立重复；Methods 2 h / Fig. 9A 3 h 的冲突继续保留。 |

**[查看 NMEVs 五条声明及完整证据定位 →](cases/nmevs-summary.md)**

历史人工确认只绑定当时声明、来源和报告版本。摘要保留机制限制及 UNVERIFIED 事项；本页没有重新评审论文，也没有将旧确认转移到新模板或封面。

## 骨盆骨折临床研究探索案例

第二篇为临床回顾性研究的迁移探索：用五条固定声明区分**样本内相关方向、调整后的独立关联、治疗比较与复算输入**。

公开摘要记录：本样本双变量相关方向得到有界支持，但所报告分析不足以支持“调整混杂后证实独立风险因素”；缺少适当常规治疗比较，不能由本队列死亡率证明治疗降低死亡率；缺少逐例配对数据和分析规格，无法独立复算。

**[查看骨盆骨折研究的五条声明与开放限制 →](cases/pelvic-fracture-summary.md)**

材料不足不表示数据错误或治疗无效。数据可用性文字冲突及其未核实的成因解释仍保留，两篇案例均不是统计复算或原始数据验证。

## 使用边界

### 四类辅助判断

| 判断 | 含义 |
|---|---|
| `SUPPORTED` | 提供且可定位的证据支持声明的该范围。 |
| `OVERREACH` | 能定位证据边界，指出声明具体扩大了哪一部分。 |
| `INSUFFICIENT_EVIDENCE` | 材料可读且可定位，但缺少判断所需的材料。 |
| `NOT_ASSESSABLE` | 材料不可读、定位缺失或存在其他审查障碍，须记录障碍。 |

这些是**辅助判断**，与工程检查的 **PASS/FAIL** 分开，不能裁决科学真伪。证据角色允许组合或“未知”，不能自动决定标签；作者写出了结论，也不自动表示所报告设计和分析支持该结论。

### 谁负责什么

| 环节 | 负责范围 |
|---|---|
| 模型或可选技能 | 依据实际材料提出有定位的辅助判断，说明理由、分歧与缺口。 |
| 确定性文件检查 | 核对文件范围、链接、记录完整性与版本摘要；不证明科学解释正确。 |
| 人工复核与确认 | 提供参考判断、依据、确认范围与日期；AI 共识不能代签。 |

- **人工字段保持独立。** AI 不代填人工确认；没有实际独立复核时，该栏目保持“未开展/未提供”。同会话技能辅助不构成独立复核，多个模拟意见一致也不构成独立验证。
- **确认绑定版本。** 新来源、新模板、新说明或新技能意见不继承旧签认。身份、资质、实际复核日期、是否盲法或预先记录答案未知时，不补造信息。
- **开放限制可保留。** 来源冲突、缺失材料和未知不必强行消除；不以摘要未提及推断全文没有证据，不借外部引用补足本研究。
- **案例不是性能证明。** 两篇案例的有界人工参照一致不构成系统准确率、独立专家认证或完整论文审核能力证明，也不能证明适用于全部科研论文。

当前交付是**文档工作流**，技能增益尚未得到充分验证。不提供自动语义判断、数据真伪裁决、整篇自动审稿或临床建议；包内没有审查算法、统计模型、API、RAG、数据库、网页或 CI。

## 可选技能协作

[可选技能协作说明](docs/optional-skills.md)规定调用时机、统一输出位置、验收和停止条件。未安装任何可选技能，仍可按本页与模板使用。

动态工作流技能只管理目标、范围和收尾；nature-reviewer 可作简短逐声明辅助，nature-statistics 可检查一个统计报告问题，缺数据时不复算。evidence-gated 只作工程约束参考，不迁移引擎。技能意见回到同一记录，注明技能、查阅范围和分歧；Elicit、scite 暂不接入，也不是使用前提。
